# Spec Delta

## MODIFIED Requirements

### Requirement: Готовые группы
У каждого пользователя SHALL быть свои три готовые группы: «Семья», «Друзья», «Коллеги». Готовые группы, которые появились при обновлении до версии с группами, принадлежат владельцу (см. `data-ownership`). Новый пользователь получает свои три пустые группы при первом входе. Это обычные группы: их можно переименовать и удалить. Удалённая или переименованная готовая группа не возвращается - ни при следующих обновлениях приложения, ни при следующих входах. Ранее добавленные контакты остаются без групп.

#### Scenario: Группы после обновления
- **WHEN** приложение обновилось до версии с группами
- **THEN** есть группы «Семья», «Друзья», «Коллеги», в каждой 0 контактов

#### Scenario: Контакты, добавленные до этой функции
- **GIVEN** до обновления в приложении были контакты с заметками
- **WHEN** приложение обновилось до версии с группами
- **THEN** у этих контактов нет групп, остальные их данные и заметки не изменились

#### Scenario: Удалённая готовая группа не возвращается
- **GIVEN** пользователь удалил группу «Коллеги»
- **WHEN** приложение обновилось до следующей версии
- **THEN** группы «Коллеги» по-прежнему нет

#### Scenario: Готовые группы нового пользователя
- **GIVEN** под boris@example.com ни разу не входили
- **WHEN** Борис входит по ссылке впервые и открывает страницу «Группы»
- **THEN** у него «Друзья - 0 контактов», «Коллеги - 0 контактов», «Семья - 0 контактов», а групп других пользователей нет

#### Scenario: Удалённая готовая группа не возвращается при следующем входе
- **GIVEN** Борис удалил свою группу «Коллеги» и вышел
- **WHEN** он снова входит по ссылке
- **THEN** группы «Коллеги» у него по-прежнему нет

### Requirement: Название группы
Название группы SHALL быть обязательным, не длиннее 50 символов; пробелы в начале и в конце не сохраняются. У одного пользователя двух групп с одинаковым названием быть не может: названия, которые отличаются только большими и маленькими буквами или буквами «е» и «ё», считаются одинаковыми. У разных пользователей названия групп могут совпадать. Ошибки: «Укажите название группы», «Название слишком длинное — не больше 50 символов», «Группа «Друзья» уже есть».

#### Scenario: Пустое название
- **WHEN** пользователь переименовывает группу и оставляет название пустым или из одних пробелов
- **THEN** появляется ошибка «Укажите название группы», название группы прежнее

#### Scenario: Слишком длинное название
- **WHEN** пользователь вписывает название группы длиннее 50 символов
- **THEN** появляется ошибка «Название слишком длинное — не больше 50 символов», группа не создаётся и не переименовывается

#### Scenario: Такое название уже есть
- **GIVEN** есть группы «Друзья» и «Теннис»
- **WHEN** пользователь переименовывает «Теннис» в «друзья»
- **THEN** появляется ошибка «Группа «Друзья» уже есть», группа по-прежнему называется «Теннис»

#### Scenario: Пробелы по краям
- **WHEN** пользователь создаёт группу « Аналитики »
- **THEN** группа сохраняется с названием «Аналитики»

#### Scenario: Одинаковые названия у разных пользователей
- **GIVEN** у A есть группа «Теннис», у B такой группы нет
- **WHEN** B создаёт группу «теннис» - на странице «Группы», в карточке или в форме контакта
- **THEN** у B появляется своя группа «теннис», ошибки нет, группа A не изменилась и в ней не прибавилось контактов
